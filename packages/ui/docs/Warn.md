# Warn

An inline caution block. Used inside the lock dialog to state the consequence before the operator commits: the customer loses the phone, emergency calls still work, the action is logged.

```tsx
<Warn>Клиент не сможет пользоваться телефоном. Экстренные вызовы останутся доступны.</Warn>
```

For anything the user must acknowledge, pair it with an explicit confirmation control.
