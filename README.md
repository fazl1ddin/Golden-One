# Golden One — Device Financing Lock

Система для кредитной организации, которая продаёт iPhone в рассрочку и должна
дистанционно блокировать устройство при просрочке — легально, через MDM (Lost Mode).

## Как это работает (коротко)
- iPhone нельзя заблокировать сторонним приложением — только через **supervised**-устройство в **вашем MDM**.
- Телефоны заводятся на точке продажи через **Apple Configurator** + managed **Activation Lock**.
- Блокировка = команда **Lost Mode** через MDM (первый вендор — **Mosyle**, за слоем-абстракцией).
- Триггер блокировки — вручную оператором взыскания (автотриггеры по просрочке — фаза 2).

Подробно: **[PLAN.md](./PLAN.md)** — архитектура, жизненный цикл устройства, роли, комплаенс, дорожная карта.

## Структура (монорепо)

| Пакет | Что это |
|---|---|
| **`packages/ui`** | Дизайн-система Golden One (направление **Console**): React-компоненты + токены. Используется приложением и синкается в Claude Design. |
| **`web`** | Админ-панель (React + Vite): дашборд, устройства, карточка, заведение, аудит, настройки. RU/UZ, тёмная/светлая тема. |
| **`api`** | Бэкенд (Fastify + Prisma + SQLite): договоры/устройства/аудит + **абстракция MDM** (`MockAdapter` / `MosyleAdapter`). |
| **`design-concepts/`** | Три концепта дизайна (Vault, Daylight, Console); загружены в Claude Design. Выбран **Console**. |
| **`prototype/`** | Ранний самодостаточный HTML-прототип (Console) — открывается в браузере без сборки. |

## Запуск

```bash
npm install                    # монорепо, все пакеты

# 1) Библиотека компонентов
cd packages/ui && npm run build

# 2) Бэкенд (нужен PostgreSQL)
cd ../../api
cp .env.example .env           # задайте DATABASE_URL и JWT_SECRET
npm run migrate:deploy
npm run seed                   # демо-данные; печатает пароли операторов
npm run dev                    # :4000

# 3) Приложение
cd ../web && npm run dev       # :5173
```

Фронтенд работает **на реальном API** — мок-данных больше нет. Адрес бэкенда
берётся из `VITE_API_URL` (по умолчанию `http://localhost:4000`, см.
`web/.env.example`). Вход обязателен: API не отдаёт ничего без токена.

Роли из `PLAN.md` отражены в интерфейсе: оператор точки продажи не видит
аудит и не получает кнопок блокировки, потому что эти запросы ему всё равно
вернут 403.
