# Golden One — Device Financing Lock

Система для кредитной организации, которая продаёт iPhone в рассрочку и должна
дистанционно блокировать устройство при просрочке — легально, через MDM (Lost Mode).

- **[PLAN.md](./PLAN.md)** — план, архитектура, жизненный цикл устройства, роли, комплаенс, дорожная карта.
- **[prototype/index.html](./prototype/index.html)** — кликабельный прототип админ-панели
  в выбранном направлении **«Console»** (плотный операторский UI, стально-циановый акцент,
  моноширинные данные). Откройте файл в браузере (сборка не нужна). Переключатель RU/UZ и тёмная/светлая тема.
- **[design-concepts/](./design-concepts/)** — три концепта дизайна (Vault, Daylight, Console),
  загружены в проект Claude Design. Выбрано направление **Console**.

## Кратко о подходе
- iPhone нельзя заблокировать сторонним приложением — только через **supervised**-устройство в **вашем MDM**.
- Телефоны заводятся на точке продажи через **Apple Configurator** + managed **Activation Lock**.
- Блокировка = команда **Lost Mode** через MDM (первый вендор — **Mosyle**, за слоем-абстракцией).
- Триггер блокировки — вручную оператором взыскания (автотриггеры по просрочке — фаза 2).

> Прототип использует демо-данные; backend не подключён. Это дизайн-макет для согласования.
